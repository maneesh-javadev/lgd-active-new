--------------------------------------------------------------------------------

      .requestMatchers("/public/v1/**", "/swagger-ui/**", "/v3/api-docs/**").permitAll()
      .anyRequest().authenticated()
  )
Lines 27-31 (authenticationEntryPoint):
  response.setStatus(HttpServletResponse.SC_UNAUTHORIZED); // 401

TECHNICAL FINDING:
  - Unauthenticated requests to '/test/**' or '/private/v1/test/**' hit Spring Security's
    filter chain FIRST, returning HTTP 401 Unauthorized ("Authentication token is missing").
  - Expecting HTTP 404 directly from unauthenticated 'wget' probes is technically impossible
    under Spring Security configuration.
  - An authenticated JWT token is MANDATORY to bypass the security filter and reach
    DispatcherServlet handler mapping evaluation (where 404 is generated when the controller
    is excluded by @Profile).
