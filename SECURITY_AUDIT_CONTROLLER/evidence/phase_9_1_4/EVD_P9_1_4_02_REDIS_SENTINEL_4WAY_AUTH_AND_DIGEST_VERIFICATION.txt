2. COMPREHENSIVE 4-WAY AUTHENTICATION VERIFICATION MATRIX:
--------------------------------------------------------------------------------
The four distinct authentication vectors required in the Stage B architecture:

Direction 1: Application Client -> Redis Data Nodes (:6379)
  - Server Directive: requirepass ${REDIS_PASSWORD}
  - Client Config: spring.data.redis.password=${SPRING_DATA_REDIS_PASSWORD}
  - Compatibility: Supported across Redis 2.0 through 8.10.3.
  - Verification: Confirmed active in redis.conf.template. Client connects via TLS
    and issues AUTH <password>.

Direction 2: Application Client -> Redis Sentinel Nodes (:26379)
  - Sentinel Directive: sentinel requirepass ${REDIS_SENTINEL_PASSWORD}
  - Client Config: spring.data.redis.sentinel.password=${REDIS_SENTINEL_PASSWORD}
  - Compatibility: Introduced in Redis 5.0.1, standardized in Redis 6.0+.
  - Verification: Confirmed active in sentinel.conf.template. Secures Sentinel
    query commands (SENTINEL masters, SENTINEL get-master-addr-by-name).

Direction 3: Sentinel Nodes -> Redis Data Nodes (:6379)
  - Sentinel Directive: sentinel auth-pass lgdmaster ${REDIS_PASSWORD}
  - Node Directive: masterauth ${REDIS_PASSWORD}
  - Compatibility: Core Sentinel directive since Redis 2.8.
  - Verification: Confirmed active in sentinel.conf.template and redis.conf.template.
    Permits Sentinels to execute PING, INFO, and failover reconfiguration
    commands (REPLICAOF) on data nodes.

Direction 4: Sentinel Nodes <-> Sentinel Nodes (Inter-Sentinel Gossip & Voting)
  - Sentinel Inbound Directive: sentinel requirepass ${REDIS_SENTINEL_PASSWORD}
  - Sentinel Outbound Directive: sentinel sentinel-pass ${REDIS_SENTINEL_PASSWORD}
  - Compatibility: 'sentinel sentinel-pass' introduced in Redis 6.2.0!
  - Flaw Identified in Phase 9.1.3:
      Phase 9.1.2 omitted 'sentinel sentinel-pass'. When Sentinel A queries
      Sentinel B via SENTINEL is-master-down-by-addr, Sentinel B demands AUTH.
      Without 'sentinel-pass', Sentinel A sends no credentials, receiving NOAUTH.
      Quorum election fails completely!
  - Correction Verified in Phase 9.1.4:
      sentinel.conf.template explicitly includes BOTH directives:
        sentinel requirepass ${REDIS_SENTINEL_PASSWORD}
        sentinel sentinel-pass ${REDIS_SENTINEL_PASSWORD}
      Because Redis 8.10.3 > 6.2.0, both directives are fully supported and mandatory.
